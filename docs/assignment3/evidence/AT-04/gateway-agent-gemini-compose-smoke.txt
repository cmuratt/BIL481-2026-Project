- Login: POST /api/v1/auth/mock-login (synthetic persona), JWT used as Bearer token

## Deployment finding (needs a compose.yaml change, Sefa's file)
With compose.yaml as it is on dev, mcp-server is only on the internal (internal: true) network and cannot reach Gemini:
the first chat request ended with an error event (log: 'Gemini request failed: TypeError'; node fetch to the Gemini host: EAI_AGAIN).
This run used a local override (not committed) that adds a second network 'egress' (plain bridge, only mcp-server on it) to mcp-server:
  networks: { egress: { driver: bridge } }   and   mcp-server.networks: [internal, egress]
After that: mcp-server -> Gemini host reachable. Isolation re-checked: web -> mcp-server:3001 BLOCKED (timeout), web -> redis:6379 BLOCKED (timeout);
host ports 3001 and 6379 not reachable; mcp-server networks: egress + internal; web network: edge only.
