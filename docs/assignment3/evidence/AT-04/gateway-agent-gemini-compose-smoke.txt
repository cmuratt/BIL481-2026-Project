## History: why compose.yaml needed a change (found in version 1 of this run)
With compose.yaml before PR #44, mcp-server was only on the internal (internal: true) network and could not reach Gemini:
the chat ended with an error event (log 'Gemini request failed: TypeError', DNS error EAI_AGAIN). PR #44 (Sefa) added a second network
'egress' used only by mcp-server and passes GEMINI_MODEL. This version of the file shows the run without any override.
